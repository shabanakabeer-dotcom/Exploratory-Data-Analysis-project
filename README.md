# Exploratory Data Analysis (EDA)

## A Python project exploring shopping trends and customer purchasing behavior using data analysis and visualization.

Tools Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

Analysis

- Univariate, Bivariate, and Multivariate Analysis
- Data visualization and interpretation
- Customer spending and purchasing patterns

Key Insights

- Clothing is the most purchased category.
- Accessories are another popular category.
- Discounts and subscriptions show no clear increase in spending.

Conclusion

This analysis helps understand customer purchasing patterns and shopping behavior.
